# ContextShare

Структурированная база знаний проекта для людей и ИИ. Здесь будут фичи,
решения, проверки и выпуски со связями, поиском и доступом через MCP.

Стартовая версия содержит веб-заглушку и проверку доступности сервиса.

## Запуск

Нужен Go 1.22 или новее. Из корня репозитория:

```sh
go run .
```

Страница доступна по адресу `http://127.0.0.1:8080/`. Для проверки сервиса
используйте `GET /healthz`. Адрес прослушивания задаётся переменной
`CONTEXTSHARE_ADDR`, по умолчанию сервис доступен только локально.
