ContextShare · MCP

Как пользоваться

  1. Выберите проект через list_projects и прочитайте get_project_overview.
  2. Ищите ноды через list_nodes и search. Для полной карточки используйте get_node, для связей — get_related_nodes.
  3. Держите у факта один источник. Различайте планы, действующие правила, подтверждение проверки и выпуск.
  4. Добавляйте идеи пакетом через add_requests. Повторите тот же operation_id, если ответ потерялся.
  5. Подготовьте заявку в вебе. Агент может взять готовую часть через claim_request, если у него есть право.

Полная версия — Markdown-памятка и команда get_usage_guide.
